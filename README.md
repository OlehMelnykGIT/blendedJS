# goit-js-hw-01

Домашки й заняття з JavaScript та конспекти до них.

## Конспект

Відкрий `konspekt/index.html` через Live Server. Там список уроків, у кожного уроку окрема сторінка
з умовами, рішеннями, поясненнями й живими демо.

```text
konspekt/
  index.html        — список уроків
  lesson-1.html     — розмітка уроку 1 (умови, код, пояснення)
  css/
    base.css        — загальні правила: кольори, тема, шрифти, кнопки, поля
    container.css   — контейнер, зміст, картка задачі, блок «Живе демо»
    demo.css        — віджети всередині демо (консоль, плитки, switch, циферблат…)
  js/
    common.js       — спільні помічники: підсвічування коду, вивід у консоль демо
    lesson-1.js     — логіка всіх демо уроку 1
```

### Як додати новий урок

1. Скопіюй `konspekt/lesson-1.html` як `lesson-2.html`, заміни задачі й підключи `js/lesson-2.js`.
2. Створи `konspekt/js/lesson-2.js`, імпортуй потрібне з `./common.js` і виклич `highlightCode()`.
3. Додай посилання на урок у `konspekt/index.html`.
4. Якщо потрібен новий віджет для демо, допиши його стилі в `css/demo.css`.

## Код задач

- `js/task-1.js` … `js/task-4.js` — домашка
- `js/lesson-1.js` — задачі з заняття 1
