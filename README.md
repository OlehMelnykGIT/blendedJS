# goit-js-hw-01

Заняття з JavaScript і конспекти до них. Відкрий `index.html` через Live Server: там список уроків.

## Структура

```text
index.html            — список уроків
lesson-N.html         — конспект уроку N
lesson-N-practice.html — пісочниця для DOM-задач (розмітка з ТЗ), з уроку 4
css/
  style.css           — єдиний файл, який підключає сторінка (імпортує решту)
  base.css            — загальні правила: кольори, тема, шрифти, кнопки, поля
  container.css       — контейнер, зміст, картка задачі, блок коду з кнопкою «Запустити»
  demo.css            — віджети для інтерактивних демо (консоль, плитки, таблиці…)
  lesson-N.css        — стилі з ТЗ для пісочниці (у конспект не підключаються)
js/
  konspekt.js         — збирає сторінку з короткої розмітки (з уроку 3)
  common.js           — спільні помічники (підсвічування коду, вивід у консоль демо)
  lesson-1.js, …      — ручні інтерактивні демо уроків 1–2
js-inKlass/
  lesson-N.js         — мій код із заняття
.vscode/
  konspekt.code-snippets — шаблони для швидкого набору
```

## Як зробити конспект нового уроку

1. Код із заняття пиши в `js-inKlass/lesson-N.js`.
2. Створи `lesson-N.html`, набери `klesson` і натисни Tab. Заповни номер, тему й вступ.
3. Для кожної задачі набери `ktask` і Tab. Далі Tab переходить між полями:
   назва, мітки, умова, код, пояснення.
4. Додай урок у `index.html`: набери `kindex` і Tab.

Решту `js/konspekt.js` зробить сам: шапку, зміст, номери задач, мітки «Умова» і «Як це працює»,
підсвічування коду, кнопки «Запустити» та «Скинути» і футер.

### Шаблони (VS Code)

| Префікс     | Що вставляє                        |
| ----------- | ---------------------------------- |
| `klesson`   | нову сторінку уроку                |
| `kpart`     | заголовок групи задач              |
| `ktask`     | задачу: умова + код + пояснення    |
| `kcode`     | блок коду з кнопкою «Запустити»    |
| `ksandbox`  | блок коду, що виконується в пісочниці |
| `kcodeview` | блок коду без запуску              |
| `kli`       | ще один пункт пояснення            |
| `knote`     | червоний блок «Зауваження до коду» |
| `kc`        | `<code>…</code>` у тексті          |
| `kindex`    | урок у списку `index.html`         |

### Мінімальна задача

```html
<article
  class="task"
  data-title="Сума елементів: reduce"
  data-chips="reduce, акумулятор"
>
  <p class="cond">Обчислити суму елементів масиву.</p>
  <script type="text/plain" class="code" data-run>
    const sum = [1, 2, 3].reduce((total, n) => total + n, 0);
    console.log(sum);
  </script>
  <ul class="how">
    <li>Колбек повертає новий акумулятор.</li>
  </ul>
  <div class="note">
    <ul>
      <li>Що було не так у моєму коді.</li>
    </ul>
  </div>
</article>
```

- Код пиши всередині `<script type="text/plain" class="code">`. Там не треба екранувати `<` і `&`,
  тож код можна вставляти як є. Відступи вирівнюються автоматично.
- `data-run` додає кнопку «▶ Запустити». Код можна змінити просто на сторінці й запустити ще раз
  (Ctrl/Cmd + Enter). Без `data-run` блок тільки показується.
- Необов'язкові атрибути задачі: `data-no="★"` (свій номер замість автоматичного), `id="..."`
  (свій якір), `data-file="..."` (інший файл у мітці; `data-file=""` прибирає мітку).
- `data-label="..."` у `.note` змінює заголовок зауваження.
- **DOM-задачі (з уроку 4).** Розмітку й стилі з ТЗ клади в `lesson-N-practice.html` і `css/lesson-N.css`,
  а в конспекті додай `data-sandbox="lesson-N-practice.html"` до `<main>` і `data-run="sandbox"` до блоку коду
  (шаблон `ksandbox`). Під кодом з'явиться ця сторінка, код виконається в ній, а не в конспекті. Кожен запуск
  починається з чистої сторінки, `<script>` пісочниці не підключаються. `data-focus=".selector"` прокручує
  пісочницю до потрібного місця. Працює тільки через Live Server (не через `file://`).
- Якщо задачі потрібне особливе інтерактивне демо, як в уроках 1–2, створи `js/lesson-N.js`
  і підключи його другим `<script type="module">` у `<head>`.
