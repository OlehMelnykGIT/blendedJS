Завдання 2. 100 випадкових чисел

У div.number-container додай 100 блоків div.number з випадковими числами від 1 до 100. Парні отримують клас even (зелений), непарні — odd (жовтий).

  • Math.random() дає число від 0 до 1 (не включно), * 100 — від 0 до 99.99…, Math.floor — 0…99, + 1 — 1…100.
  • number % 2 === 0 перевіряє, чи число парне. Тернарний оператор обирає клас.
  • Блоки спершу збираємо в масив, а потім вставляємо одним append(...items). Так браузер перемальовує сторінку один раз, а не сто.

Те саме, але розмітку збираємо рядком і вставляємо одним insertAdjacentHTML.

  • Array.from({ length: 100 }, fn) створює масив зі 100 елементів, кожен з яких повертає fn.
  • join("") склеює масив рядків в один рядок без ком між ними.

Завдання 3. Події форми

При події input: якщо в полі більше 6 символів, додай клас success, інакше error.

  • Подія input спрацьовує на кожен введений або видалений символ.
  • classList.toggle(name, condition) додає клас, якщо умова true, і прибирає, якщо false. Тому одночасно ніколи не буде обох класів.
  • trim() обрізає пробіли з країв, щоб « » не вважалось іменем.

При focus і при blur перевір, чи поле порожнє. Порожнє: outline 3px solid red. Непорожнє: 3px solid green при фокусі й 3px solid lime при blur.

  • focus — поле стало активним (клік або Tab). blur — поле втратило фокус.
  • Ці події не спливають. Тому обробник вішаємо прямо на input, а не на форму.
  • Інлайн-стиль style.outline сильніший за клас. Після першого фокусу класи success/error з 3.1 вже не буде видно. Тому кожен блок тут запускається на чистій сторінці окремо.
  • При input показуй ім'я в span замість «Anonymous». Якщо поле порожнє, повертай «Anonymous».
  • При submit відміни перезавантаження. Перевір, що ім'я не порожнє і чекбокс увімкнений. Якщо все добре, виведи { userName } у консоль, інакше покажи повідомлення.
  • Після відправки очисти поле, вимкни чекбокс і поверни «Anonymous».
  • event.preventDefault() скасовує стандартну поведінку: відправку форми з перезавантаженням сторінки.
  • form.elements містить поля форми за їхнім name: userName і accept. Значення поля — .value, стан чекбокса — .checked.
  • value.trim() || DEFAULT_NAME: порожній рядок хибний, тому підставляється «Anonymous».
  • form.reset() одним викликом очищає всі поля і знімає галочку з чекбокса. span не є полем форми, тому його повертаємо вручну.
  • return у гілці помилки зупиняє обробник, щоб далі не виконувалось виведення й скидання.

Завдання 4. Квадрат: більше / менше

«Зменшити» робить квадрат на 20px меншим, «Збільшити» — на 20px більшим.

  • offsetWidth — реальна ширина елемента в пікселях (число). box.style.width спочатку порожній, бо в HTML немає інлайн-стилю: ширина задана в CSS.
  • Поточний розмір тримаємо в змінній size, щоб не читати його зі сторінки щоразу.
  • Значення style.width — рядок з одиницями: `${size}px`. Просто число не спрацює.
  • Math.max(newSize, STEP) не дає розміру стати від'ємним.

Те саме з одним обробником на спільному батьківському div.

  • Клік по кнопці спливає до батьків. Тому один обробник на div ловить кліки обох кнопок.
  • event.target — те, по чому клікнули. За id кнопки визначаємо, що робити.
  • Зручно, коли кнопок багато або їх додають динамічно: обробник потрібен один, а не на кожну кнопку.
