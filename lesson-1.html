Купівля дроїдів

ifreturntemplate stringjs/task-1.js

Умова

Функція makeTransaction(quantity, pricePerDroid, customerCredits) рахує загальну вартість. Якщо кредитів не вистачає, повертає "Insufficient funds!", інакше повідомлення про покупку.

function makeTransaction(quantity, pricePerDroid, customerCredits) {
  const totalPrice = quantity * pricePerDroid;

  if (totalPrice > customerCredits) {
    return "Insufficient funds!";
  }

  return `You ordered ${quantity} droids worth ${totalPrice} credits!`;
}

Як це працює

  • Спочатку обчислюємо totalPrice і зберігаємо в const, бо значення далі не змінюється.
  • Ранній return: якщо грошей мало, функція одразу виходить. Тому else не потрібен.
  • Шаблонний рядок у зворотних лапках `...${}` підставляє значення змінних.

Обрізання повідомлення

lengthslicejs/task-2.js

Умова

formatMessage(message, maxLength) повертає рядок як є, якщо він не довший за maxLength. Інакше обрізає до maxLength символів і додає "...".

function formatMessage(message, maxLength) {
  if (message.length <= maxLength) {
    return message;
  }

  return message.slice(0, maxLength) + "...";
}

Як це працює

  • message.length дає кількість символів, пробіли теж рахуються.
  • slice(0, maxLength) бере символи з індексу 0 до maxLength, не включаючи його. Вихідний рядок не змінюється.

function checkForSpam(message) {

Д4

Вартість доставки

switchdefaultjs/task-4.js

Умова

getShippingCost(country) повертає вартість доставки в China, Chile, Australia, Jamaica. Для інших країн: "Sorry, there is no delivery to your country".

function getShippingCost(country) {
  let price;

  switch (country) {
    case "China":
      price = 100;
      break;
    case "Chile":
      price = 250;
      break;
    case "Australia":
      price = 170;
      break;
    case "Jamaica":
      price = 120;
      break;
    default:
      return "Sorry, there is no delivery to your country";
  }

  return `Shipping to ${country} will cost ${price} credits`;
}

Як це працює

  • switch порівнює значення строго, як ===. Тому "china" з маленької літери не знайдеться.
  • break виходить зі switch. Без нього код «провалиться» в наступний case.
  • У default стоїть return, тож функція завершується одразу і до шаблонного рядка не доходить.

Чи дорівнює число 10

promptNumber()тернарний операторjs/lesson-1.js

Умова

Запитати число через prompt(). Якщо воно дорівнює 10, вивести 'Вірно', інакше 'Невірно'.

const number = Number(prompt("Введи число"));

// варіант з if...else
if (number === 10) {
  alert("Вірно");
} else {
  alert("Невірно");
}

// той самий результат одним рядком
alert(number === 10 ? "Вірно" : "Невірно");

Як це працює

  • prompt завжди повертає рядок (або null після Cancel). "10" === 10 дає false, тому потрібен Number().
  • Number("abc") дає NaN, а Number("") дає 0.
  • Тернарний оператор умова ? так : ні повертає значення, тому його можна передати прямо в alert.

У яку чверть години потрапляє хвилина

Math.randomelse ifjs/lesson-1.js

Умова

У змінній min випадкове число від 0 до 59. Визначити чверть години і вивести, наприклад, "10 входить в першу чверть".

const min = Math.floor(Math.random() * 60); // 0…59

if (min < 15) {
  alert(`${min} входить в першу чверть`);
} else if (min < 30) {
  alert(`${min} входить в другу чверть`);
} else if (min < 45) {
  alert(`${min} входить в третю чверть`);
} else {
  alert(`${min} входить в четверту чверть`);
}

Як це працює

  • Умови перевіряються згори вниз, спрацьовує перша істинна. Тому в другій гілці достатньо min < 30: що min >= 15, вже відомо.
  • Math.random() дає число від 0 до 1 (1 не включно). Множимо на 60 і округлюємо вниз Math.floor, отримуємо 0…59.
Зауваження до коду в lesson-1.js
  • "${min} входить…" у звичайних лапках не підставляє змінну, на екрані буде буквально ${min}. Потрібні зворотні лапки `.
  • В останній гілці else "…"; немає alert, тому нічого не виводиться.
  • Math.random() * 59 ніколи не дає 59. Для 0…59 множимо на 60.

Пора року через switch

switchdefaultjs/lesson-1.js

Умова

Користувач вводить '1'…'4'. У result записати зиму, весну, літо або осінь. Інакше: "Вибачте, але ви маєте ввести значення від 1 до 4 включно".

const num = prompt("Введіть число від 1 до 4");
let result = "";

switch (num) {
  case "1":
    result = "зима";
    break;
  case "2":
    result = "весна";
    break;
  case "3":
    result = "літо";
    break;
  case "4":
    result = "осінь";
    break;
  default:
    result = "Вибачте, але ви маєте ввести значення від 1 до 4 включно";
}
console.log(result);

Як це працює

  • prompt повертає рядок, тому в case пишемо рядки "1", а не числа 1. Інакше строге порівняння не спрацює.
  • default ловить усе інше: "5", "abc", " 1" з пробілом і null після Cancel.

Хвилини у формат гг:хх

/ і %Math.floorpadStartjs/lesson-1.js

Умова

Користувач вводить кількість хвилин, у консоль виводимо години й хвилини: '70' → '01:10'.

const value = Number(prompt("Кількість хвилин"));

const hours = String(Math.floor(value / 60)).padStart(2, "0");
const minutes = String(value % 60).padStart(2, "0");

console.log(`${hours}:${minutes}`);

Як це працює

  • value / 60 дає дробові години, Math.floor відкидає дробову частину.
  • % — остача від ділення, тобто хвилини, що лишились після повних годин.
  • padStart(2, "0") доповнює рядок нулями зліва до довжини 2. Це метод рядка, тому спочатку String().

Логін і пароль

вкладений ifnulljs/lesson-1.js

Умова

Запитати логін. Для "Адмін" запитати пароль: "Я головний" → "Добрий день!", інакше "Невірний пароль!". Порожній логін або Cancel → "Скасовано". Будь-який інший логін → "Я вас не знаю".

const login = prompt("Введіть логін:");
console.log(login);

if (login === "Адмін") {
  const password = prompt("Введіть пароль:");

  if (password === "Я головний") {
    alert("Добрий день!");
  } else {
    alert("Невірний пароль!");
  }
} else if (login === null || login === "") {
  alert("Скасовано");
} else {
  alert("Я вас не знаю");
}

Як це працює

  • Cancel у prompt повертає null, а OK з порожнім полем повертає "". Перевіряємо обидва випадки.
  • Пароль запитуємо тільки всередині гілки адміна, щоб інших користувачів про нього не питати.
Зауваження до коду в lesson-1.js
  • У твоєму рішенні логін "Admin" і пароль "Password", а за умовою "Адмін" і "Я головний". Логіка правильна, відрізняються лише рядки.

Числа від 0 до 20 циклом while

whileлічильникjs/lesson-1.js

Умова

За допомогою while вивести в консоль усі числа від 0 до 20 включно.

let i = 0;

while (i <= 20) {
  console.log(i);
  i += 1;
}

Як це працює

  • Три частини циклу: початок let i = 0, умова i <= 20, крок i += 1.
  • <=, а не <, бо 20 теж має вивестись.
  • Без i += 1 умова завжди істинна, і цикл стає нескінченним.
Зауваження
  • У lesson-1.js цю задачу ще не розв'язано. Вище готове рішення.

getNumbers: від max до min і сума парних

for%typeofjs/lesson-1.js

Умова

Функція getNumbers(min, max) виводить у консоль числа від max до min за спаданням і повертає суму парних.

function getNumbers(min, max) {
  if (typeof min !== "number" || typeof max !== "number") {
    return "Not a Number!";
  }

  let sum = 0;

  for (let i = max; i >= min; i--) {
    console.log(i);
    if (i % 2 === 0) {
      sum += i;
    }
  }

  return sum;
}

console.log(getNumbers(1, 10));   // 30
console.log(getNumbers("1", 10)); // "Not a Number!"

Як це працює

  • Цикл іде назад: стартує з max, умова i >= min, крок i--.
  • i % 2 === 0 означає, що число ділиться на 2 без остачі, тобто парне.
  • typeof "1" дає "string", тому рядок не пройде перевірку.

Число без лапок передається як number, у лапках ("1") як string

min(a, b): менше з двох чисел

typeofтернарний операторjs/lesson-1.js

Умова

min(a, b) повертає менше з двох чисел. Якщо хоч один аргумент не число, повертає 'Not a number!'.

function min(a, b) {
  if (typeof a !== "number" || typeof b !== "number") {
    return "Not a number!";
  }

  return a < b ? a : b; // або Math.min(a, b)
}

console.log(min(2343, 101)); // 101

Як це працює

  • Спочатку валідація, тобто перевірка вхідних даних, потім основна логіка.
  • a < b ? a : b: якщо a менше, повертаємо його, інакше b.
Зауваження до коду в lesson-1.js
  • (a, b ? a : b) — це оператор «кома»: він обчислює a, відкидає його і повертає b ? a : b. Порівняння тут немає. Правильно: a < b ? a : b.
  • Коментарі /* … */ не вкладаються. Внутрішній */ закриває зовнішній коментар раніше, ніж очікуєш. Те саме в задачах 1 і 10. Щоб вимкнути блок, краще виділи його і натисни Ctrl/Cmd + /.

isAdult: повнолітній чи ні

||коротке замиканняconfirmjs/lesson-1.js

Умова

isAdult(age) повертає true, якщо age >= 18. Інакше питає підтвердження через confirm і повертає його результат.

function isAdult(age) {
  // довгий варіант
  // if (age >= 18) {
  //   return true;
  // }
  // return confirm("Вам дійсно 18?");

  return age >= 18 || confirm("Вам дійсно 18?");
}

Як це працює

  • || обчислюється зліва направо і зупиняється на першому істинному значенні. Це коротке замикання.
  • Якщо age >= 18, результат уже true, і confirm навіть не викликається.
  • Якщо ні, || повертає те, що повернув confirm: true для OK або false для Скасувати.

fizzBuzz

for%порядок умовjs/lesson-1.js

Умова

Для кожного числа від 1 до num: ділиться на 3 → 'fizz', на 5 → 'buzz', і на 3, і на 5 → 'fizzbuzz'.

function fizzBuzz(num) {
  for (let i = 1; i <= num; i++) {
    if (i % 3 === 0 && i % 5 === 0) {
      console.log("fizzbuzz");
    } else if (i % 3 === 0) {
      console.log("fizz");
    } else if (i % 5 === 0) {
      console.log("buzz");
    } else {
      console.log(i);
    }
  }
}

fizzBuzz(15);

Як це працює

  • Порядок умов важливий: перевірку «на 3 і на 5» ставимо першою. Інакше 15 зловить гілка % 3, і ми отримаємо лише fizz.
  • i % 3 === 0 && i % 5 === 0 можна записати коротше: i % 15 === 0.
